title: "Coupons and add-ons"
description: "Discounts applied to customers, and one-off items for one-off invoices."
---

## Coupons

| Command | Description |
| --- | --- |
| `coupons create` | Create a coupon. |
| `coupons get <code>`, `list` | Read coupons. |
| `coupons update <code>` | Update a coupon. |
| `coupons delete <code>` | Delete. Confirmation-gated. |
| `coupons apply` | Apply a coupon to a customer. |
| `coupons list-applied-coupons` | Applied coupons across customers. |
| `coupons delete-applied-coupon <external_customer_id> <applied_coupon_id>` | Remove an applied coupon. Confirmation-gated. |

| Flag | Description |
| --- | --- |
| `--coupon-type fixed_amount\|percentage` | With `--amount-cents` and `--amount-currency`, or `--percentage-rate`. |
| `--frequency once\|recurring\|forever` | `recurring` takes `--frequency-duration` in billing periods. |
| `--reusable true` | The same coupon can be applied to a customer more than once. |
| `--expiration no_expiration\|time_limit` | `time_limit` takes `--expiration-at`. |
| `--applies-to-plan-codes`, `--applies-to-billable-metric-codes` | JSON arrays. Limit the discount's scope. |

`apply` can override the amount or percentage for one customer. The applied coupon's `lago_id` is what `delete-applied` takes.

## Add-ons

| Command | Description |
| --- | --- |
| `add-ons create` | Create an add-on. |
| `add-ons get <code>`, `list` | Read add-ons. |
| `add-ons update <code>` | Update. |
| `add-ons delete <code>` | Delete. Confirmation-gated. |

Add-ons are the line items of a one-off invoice. See `invoices create` on the [invoices page](/guide/lago-cli/commands/invoices).

<RequestExample>

```bash coupons create
lago coupons create --name "Launch 20%" --code launch20 \
  --coupon-type percentage --percentage-rate 20 \
  --frequency recurring --frequency-duration 3 \
  --reusable true --expiration no_expiration

lago coupons create --name "Credit 50" --code credit50 \
  --coupon-type fixed_amount --amount-cents 5000 --amount-currency USD \
  --frequency once --applies-to-plan-codes '["pro"]'
```

```bash coupons apply
lago coupons apply --coupon-code launch20 --external-customer-id acme_001
lago coupons list-applied-coupons --output json \
  --query 'applied_coupons[?external_customer_id==`"acme_001"`].{id: lago_id, code: coupon_code}'
lago coupons delete-applied-coupon acme_001 8b908b90-8b90-8b90-8b90-8b908b908b90 \
  --confirm 8b908b90-8b90-8b90-8b90-8b908b908b90
```

```bash coupons read
lago coupons get launch20
lago coupons list
lago coupons delete launch20 --confirm launch20
```

```bash add-ons
lago add-ons create --name Onboarding --code setup_fee \
  --amount-cents 50000 --amount-currency USD --invoice-display-name "Onboarding package"
lago add-ons list
lago add-ons update setup_fee --amount-cents 45000
lago add-ons delete setup_fee --confirm setup_fee
```

</RequestExample>
