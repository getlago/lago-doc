---
title: "Prorated vs Full"
description: "Usage-based charges can be either billed fully or prorated based on the number of days used."
---

A usage-based charge is either **prorated or fully-billed**. The difference is
how Lago charges a unit added mid-period: prorated charges bill it for the days
it was used, fully-billed charges bill it for the whole period.

## Prorated charges

<Tabs>
  <Tab title="Dashboard">
    <Warning>
      Only charges that are [recurring](/guide/plans/charges/metered-vs-recurring#recurring-charges) (billable metric with `recurring` argument set to `true`), invoiced [in arrears](/guide/plans/charges/arrears-vs-advance), with a `charge_model` defined to `standard`, `graduated` or `volume` can be prorated. If your charge is pay-in-advance, it can only be prorated if the `charge_model` is `standard`. 
    </Warning>
    Set the `prorated` parameter to `true` to prorate a charge. A unit added
    during the billing period is then charged for the number of days it was
    used, not for the whole period.

    Take prorated `Seats`, where each seat costs \$10. A seat added on July 10th
    is used for 22 days of the period, so Lago charges it for those 22 days:

    _Example: (1 Seat x \$10), used for 22 days = \$7.33_
  </Tab>
  <Tab title="API">
    Create a charge that is prorated by setting `prorated` to `true`.

    <Warning>
      Only charges that are [recurring](/guide/plans/charges/metered-vs-recurring#recurring-charges) (billable metric with `recurring` argument set to `true`), invoiced [in arrears](/guide/plans/charges/arrears-vs-advance), with a `charge_model` defined to `standard`, `graduated` or `volume` can be prorated. If your charge is pay-in-advance, it can only be prorated if the `charge_model` is `standard`. 
    </Warning>
    <CodeGroup>

    ```bash Prorated charges {25}
      LAGO_URL="https://api.getlago.com"
      API_KEY="__YOUR_API_KEY__"
    
      curl --location --request POST "$LAGO_URL/api/v1/plans" \
      --header "Authorization: Bearer $API_KEY" \
      --header 'Content-Type: application/json' \
      --data-raw '{
        "plan": {
          "name": "Startup",
          "code": "startup",
          "interval": "monthly",
          "description": "This is a basic plan description",
          "amount_cents": 10000,
          "amount_currency": "USD",
          "trial_period": 3.0,
          "pay_in_advance": true,
          "bill_charges_monthly": false,
          "charges": [
            {
              "billable_metric_id": "__BILLABLE_METRIC_ID__",
              "charge_model": "standard",
              "pay_in_advance": true,
              "invoiceable": true,
              "min_amount_cents": 0,
              "prorated": true,
              "properties": {
                "amount": "10"
              }
            }
          ]
        }
      }'
    ```

    </CodeGroup>
  </Tab>
</Tabs>

## Fully-billed charges

<Tabs>
  <Tab title="Dashboard">
    <Warning>
      Note that metered charges (billable metrics with `recurring` set to `false`) are automatically fully-billed.
    </Warning>
    Set the `prorated` parameter to `false` to bill a charge in full. A unit
    added during the billing period is then charged for the whole period,
    whatever the number of days it was used.

    Take fully-billed `Seats`, where each seat costs \$10. A seat added on July
    10th is used for 22 days of the period, and is still charged in full:

    _(1 Seat x \$10), used for 22 days = \$10._
  </Tab>
  <Tab title="API">
    Create a charge that is billed fully by setting `prorated` to `false`.

    <Warning>
      Note that metered charges (billable metrics with `recurring` set to `false`) are automatically fully-billed.
    </Warning>
    <CodeGroup>

    ```bash Fully-billed charges {25}
      LAGO_URL="https://api.getlago.com"
      API_KEY="__YOUR_API_KEY__"
    
      curl --location --request POST "$LAGO_URL/api/v1/plans" \
      --header "Authorization: Bearer $API_KEY" \
      --header 'Content-Type: application/json' \
      --data-raw '{
        "plan": {
          "name": "Startup",
          "code": "startup",
          "interval": "monthly",
          "description": "This is a basic plan description",
          "amount_cents": 10000,
          "amount_currency": "USD",
          "trial_period": 3.0,
          "pay_in_advance": true,
          "bill_charges_monthly": false,
          "charges": [
            {
              "billable_metric_id": "__BILLABLE_METRIC_ID__",
              "charge_model": "standard",
              "pay_in_advance": true,
              "invoiceable": true,
              "min_amount_cents": 0,
              "prorated": false,
              "properties": {
                "amount": "10"
              }
            }
          ]
        }
      }'
    ```

    </CodeGroup>
  </Tab>
</Tabs>
