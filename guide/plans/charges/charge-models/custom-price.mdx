The default charge models, such as standard, graduated or percentage, cover
most pricing. When your product needs a rule they cannot express, Lago parses
custom pricing logic that you supply as JSON.

Set this logic in the `custom_properties` attribute of a charge. You can edit
it later, and override it for a particular subscription.

Here is an example of a custom price model defining tiers across multiple properties:
```json
"properties": {
    "custom_properties": {
        "ranges": [
            { "from": 0, "to": 10, "storage_eu": "0", "storage_us": "0", "storage_asia": "0" },
            { "from": 10, "to": 20, "storage_eu": "0.10", "storage_us": "0.20", "storage_asia": "0.30" },
            { "from": 20, "to": null, "storage_eu": "0.20", "storage_us": "0.30", "storage_asia": "0.40" }
        ]
    }
}
```
