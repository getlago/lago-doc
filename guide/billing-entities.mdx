## Create a billing entity

Billing entities let you manage your end customers under distinct billing configurations.

To create a billing entity, follow these steps:

<Tabs>
  <Tab title="Dashboard">
    Using the user interface:
    1. Click **Settings** in the side navigation bar.
    2. In the **Settings** menu, click **"Add a billing entity"**.
    3. Enter a **name** and a **unique code** for your billing entity.
    4. Configure the entity’s settings as needed.
    5. Click **"Add billing entity"** to confirm.
  </Tab>
  <Tab title="API">
    <CodeGroup>
    ```bash Create a billing entity
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"

    curl --location --request POST "$LAGO_URL/api/v1/billing_entities" \
      --header "Authorization: Bearer $API_KEY" \
      --header 'Content-Type: application/json' \
      --data-raw '{
        "billing_entity": {
          "code": "acme_corp",
          "name": "Acme Corporation",
          "document_number_prefix": "ACM",
          "billing_configuration": {
            "invoice_footer": "Thank you for your business"
          }
        }
      }'
    ```
    </CodeGroup>
  </Tab>
</Tabs>

<Info>
  The first billing entity created in your organization is considered the **default**.

  Billing entity settings only apply to the customers assigned to that specific entity. More information is available in the following sections.
</Info>

## Edit a billing entity

You can update all billing entity information **except the code** after creation.

To edit a billing entity:

<Tabs>
  <Tab title="Dashboard">
    Using the user interface:
    1. Click **Settings** in the side navigation bar.
    2. In the **Settings** menu, select the relevant billing entity.
    3. Click any section to edit its settings.
  </Tab>
  <Tab title="API">
    <CodeGroup>
    ```bash Update a billing entity
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"

    BILLING_ENTITY_CODE="acme_corp"

    curl --location --request PUT "$LAGO_URL/api/v1/billing_entities/$BILLING_ENTITY_CODE" \
      --header "Authorization: Bearer $API_KEY" \
      --header 'Content-Type: application/json' \
      --data-raw '{
        "billing_entity": {
          "name": "Acme Corporation",
          "document_number_prefix": "ACM",
          "billing_configuration": {
            "invoice_footer": "Thank you for your business"
          }
        }
      }'
    ```
    </CodeGroup>
  </Tab>
</Tabs>

## Billing entity settings

A billing entity carries the settings that Lago applies to the invoices it issues:

| Setting | Field |
|---|---|
| Entity details, logo and [invoice footer](/guide/invoicing/invoicing-settings/overview#add-a-custom-footer) | `legal_name`, `legal_number`, `tax_identification_number`, the address fields, `logo`, `billing_configuration.invoice_footer` |
| Default currency and timezone | `default_currency`, `timezone` |
| [Invoice numbering](/guide/invoicing/invoicing-settings/invoice-numbering) | `document_numbering`, `document_number_prefix` |
| [Grace period](/guide/invoicing/invoicing-settings/grace-period) | `billing_configuration.invoice_grace_period` |
| [Net payment term](/guide/invoicing/invoicing-settings/net-payment-term) | `net_payment_term` |
| [Document language](/guide/invoicing/invoicing-settings/overview#translate-invoices) | `billing_configuration.document_locale` |
| [Zero-amount invoices](/guide/invoicing/invoicing-settings/empty-invoices) | `finalize_zero_amount_invoice` |
| [Taxes](/guide/invoicing/invoicing-settings/taxes) | `tax_codes`, `eu_tax_management` |
| [Invoice custom sections](/guide/invoicing/invoicing-settings/overview#add-a-custom-invoice-section) | `invoice_custom_section_codes` |
| [Emails](/guide/emails) | `email`, `email_settings` |
| [E-invoicing](/guide/invoicing/e-invoicing/overview) | `einvoicing` |

`tax_codes` and `invoice_custom_section_codes` are only accepted when you update a billing entity, not when you create one.

## Delete a billing entity

Deleting a billing entity is **not available** via the Dashboard or API.

<Info>
  To delete a billing entity, contact the Lago team directly.
</Info>

---

## Assign a billing entity to a customer

When creating a customer, you can assign it to a billing entity in two ways:

- Through the Dashboard by selecting the billing entity.
- Via API by passing the `billing_entity_code` in the customer creation payload.

If you do not pass `billing_entity_code`, Lago assigns the customer to the **default** billing entity.

<Info>
  The billing entity assigned to a customer acts as their **default billing entity**.
</Info>

A customer is not limited to a single billing entity: when creating a billing object for the customer (e.g. a subscription, one-off invoice, or wallet), you can select a billing entity different from the customer's default. The resulting invoices are issued by the billing entity selected on the object.
