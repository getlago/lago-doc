Once a plan is assigned to a customer, you can edit the subscription, whether it is pending or active:

<Tabs>
  <Tab title="Dashboard">
  1. Click the three dots menu icon and select **"Edit subscription"**;
  2. **Subscription start date**   
  You can modify the subscription start date if the subscription is pending and the chosen date is later than today. See the [guidelines for subscription start date](/guide/subscriptions/assign-plan#subscription-start-date);
  3. **Subscription end date**   
  You can also change the subscription end date. See the [guidelines for subscription end date](/guide/subscriptions/assign-plan#subscription-end-date); and
  4. You can edit any prices listed for a subscription, including charges, commitments, tiers and spending minimums.
  5. In **Invoicing settings**, you can [change the subscription's payment term](#change-payment-terms) or restore inheritance from the customer.
  </Tab>
  <Tab title="API">
    <CodeGroup>
    ```bash Edit a subscription
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"
    EXTERNAL_ID="__YOUR_SUBSCRIPTION_ID__"

    curl --location --request PUT "$LAGO_URL/api/v1/subscriptions/$EXTERNAL_ID" \
      --header "Authorization: Bearer $API_KEY" \
      --header 'Content-Type: application/json' \
      --data-raw '{
      "subscription": {
        "name": "Repository 1",
        "subscription_at": "2022-08-08T00:00:00Z",
        "ending_at": "2023-08-08T00:00:00Z",
        "plan_overrides": {
          "name": "new_plan",
          "invoice_display_name": "Subscription fee",
          "description": "Overridden plan for customer X",
          "charges": [
            {
              "id": "cac4cff7-e2d9-41e2-83e5-7947d91f0eb5",
              "invoice_display_name": "Cards - custom price",
              "properties": {
                "amount": "10"
              }
            }
          ],
          "fixed_charges": [
            {
              "id": "af360881-357a-4334-ad16-8cd38e246d03",
              "units": 20,
              "apply_units_immediately": true
            }
          ]
        }
      }
    }'
    ```
    </CodeGroup>
  </Tab>
</Tabs>

<Info>
  Fixed charges are updated under `plan_overrides`, using the `fixed_charges` array. Sending only `units` (and `apply_units_immediately` if needed) updates the quantity without creating a plan override. Passing a price or `properties` creates one. See [Update a fixed charge via the API](/guide/plans/charges/fixed-charges#update-a-fixed-charge-via-the-api).
</Info>

## Change payment terms

On the subscription overview, the current term appears under **Invoicing settings**, with an inheritance hint when the subscription has none of its own. Click **Edit**, choose the payment-term type and its days or month settings, then save. To return to the customer's default, choose the inheritance option. See [Payment terms](/guide/invoicing/invoicing-settings/payment-term#choose-a-payment-term) for the available options and examples.

For example, change a subscription from **Net 30** to **Net 60** after negotiating a longer payment window. A new invoice dated **April 10, 2026** is due **June 9** instead of **May 10**. The customer's other subscriptions keep their own or inherited terms.

Existing invoices, including drafts, keep the payment term they were created with. Different effective terms also affect [whether subscriptions can share an invoice](/guide/subscriptions/assign-plan#invoice-consolidation).
