Quotes & Order Forms lets you build pricing proposals directly in Lago instead of external documents. The proposal is assembled from your Lago catalog: plans, coupons, prepaid credits, add-ons. When the deal closes, the same configuration provisions billing. What you quote is what gets billed.

## From quote to order

The feature revolves around three documents. Each one is created from the previous one.

1. A **Quote** is the internal negotiation document. You write it, add pricing, and edit it freely. During negotiation you can create new versions of the same quote.
2. An **Order Form** is the formal document generated when you approve a quote. It is frozen: nobody can edit it. You download it as a PDF and send it to the customer for signature.
3. An **Order** is created when you mark the order form as signed. It is the permanent record of the agreement. Executing the order provisions billing in Lago, or records the deal if billing runs elsewhere.

```
Quote (draft) ──approve──▶ Order Form ──mark as signed──▶ Order ──execute──▶ Billing
   edit, version              send PDF for signature       permanent record    subscriptions, coupons,
                                                                               wallets, invoices
```

## Statuses at a glance

| Document | Statuses |
| --- | --- |
| Quote version | Draft, Approved, Voided |
| Order form | Generated, Signed, Expired, Voided |
| Order | Created, Executed |

## Permissions

Quotes & Order Forms follows Lago's [roles and permissions](/guide/security/rbac). Admins and managers can create, edit, approve, void, and duplicate quotes, sign and void order forms, and execute orders. The Finance role is view-only across quotes, order forms, and orders.
