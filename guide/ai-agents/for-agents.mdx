Use your coding agent to explore Lago, model your pricing, and add billing to your application. The [Lago plugin](https://github.com/getlago/lago-plugin) gives the agent an offline example and an implementation workflow. You can start without a Lago account. Connect to a Lago Cloud organization or self-hosted instance when you are ready to check real usage and billing data.

## Pick your agent

<Tabs>
  <Tab title="Claude Code">
    Run in Claude Code:

    ```text
    /plugin marketplace add getlago/lago-plugin
    /plugin install lago@lago-plugins
    ```

    Then ask: `/lago:implementation show me what Lago can do`
  </Tab>
  <Tab title="Codex">
    Run in your terminal:

    ```bash
    codex plugin marketplace add getlago/lago-plugin
    codex plugin add lago@lago-plugins
    ```

    Start a new Codex task, then ask: `$lago:implementation show me what Lago can do; do not assume this workspace is my application`
  </Tab>
  <Tab title="Gemini CLI">
    Run in your terminal:

    ```bash
    gemini extensions install https://github.com/getlago/lago-plugin
    ```

    Then ask: `Use the Lago implementation skill to show me what Lago can do.`
  </Tab>
  <Tab title="GitHub Copilot CLI">
    Run in your terminal:

    ```bash
    copilot plugin marketplace add getlago/lago-plugin
    copilot plugin install lago@lago-plugins
    ```

    Then ask: `Use the Lago implementation skill to show me what Lago can do.` The local plugin install and offline demo were tested; the GitHub marketplace command has not been separately tested.
  </Tab>
  <Tab title="Cursor">
    In Cursor, open **Customize → From GitHub Repository** and enter `getlago/lago-plugin`. The manifest is published, but this install has not been tested in Cursor.
  </Tab>
  <Tab title="Other agents">
    If your agent supports Agent Skills, install the implementation skill:

    ```bash
    npx skills add getlago/lago-plugin --skill implementation
    ```

    This installs the skill without the plugin's bundled offline demo.
  </Tab>
</Tabs>

[Local checks](https://github.com/getlago/lago-plugin/tree/main/docs/release-evidence/agents-2026-10-19) ran the offline demo in Gemini CLI and GitHub Copilot CLI. They did not test automatic skill selection or an application billing integration. The Claude Code and Codex paths are the plugin's primary installs.

If your agent cannot install the plugin or a skill, give it the [one-page Lago starter](https://github.com/getlago/lago-plugin/blob/main/START_HERE.md), which includes the offline example and Node.js/TypeScript and Python integration code.

## Give the agent a task

**Just exploring?** After installing the plugin, ask it to use the Lago implementation skill to show you what Lago can do. The example runs offline, so you do not need an application repository or API key.

**Adding billing to an app?** Open your application repository in the agent and paste:

```text
Build billing on Lago in this app. Inspect the code and our current billing.
Before editing, show who pays, what usage we would send, how the bill is
calculated, and which system handles subscriptions, invoices, and payments.
Then implement the smallest useful slice and test the money offline.
Ask before changing existing billing or accessing a live Lago organization.
```

For the full workflow, including a sample application, CLI commands, and billing checks, follow [Build Lago billing with a coding agent](/guide/lago-cli/coding-agents).

## Connect to Lago when you are ready

To read or configure a real organization, use the [Lago CLI](/guide/lago-cli/overview) or [product MCP server](/guide/ai-agents/mcp-server). These are separate from the plugin. Your application uses a [Lago SDK or the REST API](/developers) at runtime.

| Tool | What it gives your agent | Lago API key? |
| --- | --- | --- |
| [Lago plugin](https://github.com/getlago/lago-plugin) | Guided billing examples and implementation instructions | No, for offline work |
| [Documentation MCP](https://docs.getlago.com/mcp) | Search of Lago's public docs | No |
| [Lago CLI](/guide/lago-cli/overview) | Terminal commands to inspect, configure, and verify a Lago organization | Yes, for live commands |
| [Product MCP](/guide/ai-agents/mcp-server) | Supported tools that access an organization's billing data | Yes |
| [SDK or REST API](/developers) | Your application's server-side billing integration | Yes |

For live access, use the **Lago Cloud organization your team invited you to**, or [deploy self-hosted Lago](/guide/lago-self-hosted/overview). Confirm the Cloud region or your self-hosted API URL. In that same organization, get an API key from **Developers → API keys**. Then follow the [CLI setup and verification steps](/guide/lago-cli/coding-agents#2-connect-to-the-right-lago-organization). Keep the key out of prompts and source control.

The plugin does not bundle the CLI or either MCP connection. If you want your agent to look up exact event or pricing guidance while coding, add `https://docs.getlago.com/mcp` as a remote HTTP MCP server. It searches public docs and cannot read your organization's data.
