---
title: "The quote version object"
openapi-schema: "QuoteVersionObjectExtended"
description: "This object represents a version of a quote: the priced deal itself, as a document `content` and a set of `billing_items`. A quote carries one active version at a time, and every renegotiation creates a new one by cloning."
---

<Info>
  The keys of `billing_items` are camelCased, unlike the rest of the API. They are stored as authored in the Lago user interface, and every `payload` pins the catalog record the entry was built from.
</Info>
