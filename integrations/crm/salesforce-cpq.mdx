## II. Configuration to sync data

### Assign permissions
Assign `Lago CPQ Permission` to users who need to access Lago for Salesforce CPQ.

### Include Lago fields in the 'Quote Line Items editor' layout
Update the "Edit Line" available in the Quote Layout to enter the details related to Lago fields in QuoteLine, with the steps below:
  1. Go to Setup;
  2. Click on Object manager;
  3. Go to the `Quote Line` object;
  4. Click on `Field Sets`;
  5. Select edit on the `Line Editor` field set; and
  6. Make sure the following fields are available in the field set:
      - Lago Name
      - Lago External Id
      - Lago Billing Time
      - Lago Start Date
      - Lago End Date

## III. Actions from Salesforce to Lago
Beyond just syncing data from Lago to Salesforce, you can also initiate actions in Lago directly from Salesforce. 
You can leverage Salesforce `Flows` to execute actions in Lago. Lago provides customizable templates for creating subscriptions from Salesforce Accounts, assigning subscriptions to customers from Salesforce, and creating one-off invoices from Salesforce.

### Create customers [from Lago to Salesforce CRM](/integrations/crm/salesforce-crm#flow-lago-template-create-customer-in-lago-on-account-create)

### Create subscriptions (automation)

Assigning a plan to a customer, adjusting negotiated prices, and initiating the subscription upon accepting a quote represents a key action from Salesforce to Lago. 

To assign a subscription and set prices in Lago directly from Salesforce, use the Lago Flow templates below.

#### Flow 1: `LagoCPQ Template - Quote Line After Insert`

This Flow is used to update the Subscription External Id when it is null.

1. Log into your Salesforce instance;
2. Access the Setup section via the settings gear icon in Salesforce;
3. Find and select `Flows` under Process Automation in the sidebar;
4. Locate and open the `LagoCPQ Template - Quote Line After Insert`;
5. Click 'Save As' to create and save your own version of the template; and
6. Do not forget to click the `Activate` button to activate your flow.

The default setting triggers plan assignment when the Lago subscription external id is null. You can customize this flow to suit your specific needs.

#### Flow 2: Pre-requisite from Lago to Salesforce CRM package: `Lago Template - Create Subscription in Lago on Subscription Creation/Update`

This Flow is used to create subscriptions in Lago from Salesforce.

1. Log into your Salesforce instance;
2. Access the Setup section via the settings gear icon in Salesforce;
3. Find and select `Flows` under Process Automation in the sidebar;
4. Locate and open the `Lago Template - Create Subscription in Lago on Subscription Creation/Update`;
5. Click 'Save As' to create and save your own version of the template; and
6. Do not forget to click the `Activate` button to activate your flow.

The default setting triggers plan assignment when the `SyncToLago` checkbox is checked. You can customize this flow to suit your specific needs.

#### Flow 3: `LagoCPQ Template - Create Lago SObject Records Using Quotes`

This Flow is used to create Lago subscription records in Salesforce when the Quote status changes to Approved.

1. Log into your Salesforce instance;
2. Access the Setup section via the settings gear icon in Salesforce;
3. Find and select `Flows` under Process Automation in the sidebar;
4. Locate and open the `LagoCPQ Template - Create Lago SObject Records Using Quotes`;
5. Click 'Save As' to create and save your own version of the template; and
6. Do not forget to click the `Activate` button to activate your flow.

The default setting triggers plan assignment when the Quote status changes to Approved. You can customize this flow to suit your specific needs.

### Terminate a subscription

We can terminate the subscription from Salesforce in Lago only if the subscription is already synced to Lago (status is _active_ or _pending_).

Go to the Lago Subscription record in Salesforce, and check the `Terminate Subscription` checkbox.

    <Info>
    As soon as `Terminate Subscription` is checked it will terminate the subscription in Lago. It is handled from the backend via trigger.
    </Info>


## Debugging & logs

Every action and data transfer between Lago and Salesforce is logged. The logs are accessible through the Lago package:

1. Navigate to 'Lago Base Configuration', the starting point for the debugging tools; and
2. Access Logs: Click on the 'Logs' tab to view a detailed record of all activities.

You can refresh the logs to keep them current, or delete the ones you no longer need.
