title: "Data Pipeline schema"
description: "Every table and column synced by Lago Data Pipeline"
---

This page lists every table and column that [Lago Data Pipeline](/integrations/data/lago-data-pipeline) syncs to your destination, grouped by domain. Open a table to see its columns, in the order they appear in your destination.

- `lago_id` is the primary key of every table.
- `updated_at` drives incremental syncs: a row is synced again when its `updated_at` changes.
- Amounts in `_cents` columns are in the smallest unit of the currency, for example cents for USD or EUR.
- Timestamps are in UTC.
- Organizations billing with plans and subscriptions and organizations billing with the product catalog share the same tables. Tables or columns that only apply to one of them are marked, and stay empty for the other. Columns for the product catalog are always added after the existing columns of a shared table.

    | `firstname` | string | First name of the customer. |
    | `lastname` | string | Last name of the customer. |
    | `customer_type` | string | Type of the customer: `company` or `individual`. Empty when not set. |
    | `sequential_id` | bigint | Number of the customer within the organization, reflecting its order of creation. |
    | `slug` | string | Short unique identifier of the customer, built from the organization and the customer's `sequential_id`. |
    | `created_at` | timestamp | Date and time the customer was created, in UTC. |
    | `updated_at` | timestamp | Date and time the customer was last updated, in UTC. |
    | `deleted_at` | timestamp | Date and time the customer was deleted, in UTC. Empty for active customers. |
    | `country` | string | Country code of the customer's billing address, in ISO 3166 alpha-2 format. |
    | `address_line1` | string | First line of the customer's billing address. |
    | `address_line2` | string | Second line of the customer's billing address. |
    | `state` | string | State of the customer's billing address. |
    | `zipcode` | string | Zipcode of the customer's billing address. |
    | `email` | string | Email of the customer. |
    | `city` | string | City of the customer's billing address. |
    | `url` | string | Custom website URL of the customer. |
    | `phone` | string | Phone number of the customer. |
    | `legal_name` | string | Legal company name of the customer. |

    | `timezone` | string | Timezone set on the customer, used for billing in their local time. Empty when the customer has no timezone of its own. |

    | `vat_rate` | float | Legacy VAT rate field on the customer. Taxes applied to the customer are listed in `customers_taxes`. |
    | `applicable_invoice_grace_period` | integer | Invoice grace period in days that applies to the customer: its own value, else the organization's value. |
    | `document_locale` | string | Language of the documents issued for the customer, in ISO 639-1 format. Empty when the customer has no locale of its own. |
    | `provider_customer_id` | string | Customer ID within the payment provider's system, from the customer's payment provider record. |
    | `provider_settings` | json | Settings of the customer's payment provider record, such as `provider_mandate_id`, `payment_method_id` or `sync_with_provider`. |
    | `metadata` | json | Always an empty object in this table. |
    | `lago_taxes_ids` | json | Always an empty array in this table. The taxes applied to a customer are listed in `customers_taxes`. |

  </Accordion>
</AccordionGroup>

## Billable metrics

<AccordionGroup>
  <Accordion title="billable_metrics">
    One row per billable metric. Deleted billable metrics are excluded.

    | Column | Type | Description |
    | --- | --- | --- |
    | `organization_id` | string | Unique identifier of the organization, assigned by Lago. |
    | `lago_id` | string | Unique identifier of the billable metric, assigned by Lago. |
    | `name` | string | Name of the billable metric. |
    | `code` | string | Unique code of the billable metric, used to associate each event with the correct metric. |
    | `description` | string | Internal description of the billable metric. |
    | `aggregation_type` | string | Aggregation method used to compute usage: `count_agg`, `sum_agg`, `max_agg`, `unique_count_agg`, `weighted_sum_agg`, `latest_agg`, `custom_agg` or `unknown`. |
    | `weighted_interval` | string | Time interval used to weight usage with the `weighted_sum_agg` aggregation type: `seconds`. Empty for other aggregation types. |
    | `recurring` | boolean | Whether the accumulated number of units carries over from one billing period to the next instead of resetting to 0. |
    | `rounding_function` | string | Rounding applied to the aggregated number of units: `round`, `ceil` or `floor`. Empty when units are not rounded. |
    | `rounding_precision` | integer | Number of decimal places kept when `rounding_function` is applied. It can be positive or negative. |
    | `created_at` | timestamp | Date and time the billable metric was created, in UTC. |
    | `updated_at` | timestamp | Date and time the billable metric was last updated, in UTC. |
    | `field_name` | string | Event property used to aggregate usage. Empty when `aggregation_type` is `count_agg`. |
    | `expression` | string | Expression evaluated for each event to calculate its units. |
    | `filters` | json | Filters of the billable metric, as an array of objects with a `key` (the event property) and its possible `values`. Empty array when there are no filters. |

  </Accordion>
</AccordionGroup>

## Plans and subscriptions

<AccordionGroup>
  <Accordion title="charges">
    One row per usage-based charge of a plan, including deleted charges.

    Plans and subscriptions only: empty for organizations billing with the product catalog.

    | Column | Type | Description |
    | --- | --- | --- |
    | `organization_id` | string | Unique identifier of the organization, assigned by Lago. |
    | `lago_id` | string | Unique identifier of the charge, assigned by Lago. |
    | `lago_billable_metric_id` | string | Unique identifier of the billable metric the charge prices, assigned by Lago. |
    | `lago_plan_id` | string | Unique identifier of the plan the charge belongs to, assigned by Lago. |
    | `invoice_display_name` | string | Name displayed on invoices for this charge. When empty, the name of the billable metric is used. |
    | `created_at` | timestamp | Date and time the charge was created, in UTC. |
    | `updated_at` | timestamp | Date and time the charge was last updated, in UTC. |
    | `deleted_at` | timestamp | Date and time the charge was deleted, in UTC. Empty while the charge exists. |
    | `charge_model` | string | Pricing model of the charge: `standard`, `graduated`, `package`, `percentage`, `volume`, `graduated_percentage`, `custom` or `dynamic`. |
    | `invoiceable` | boolean | Whether the charge is included in an invoice. When `false`, no invoice is issued for this charge. It can only be `false` when `pay_in_advance` is `true`. |
    | `regroup_paid_fees` | string | Set to `invoice` when the paid-in-advance fees of a non-invoiceable charge are consolidated into an invoice at the end of the period once their payment succeeded. Empty when no invoice is issued for them. |
    | `pay_in_advance` | boolean | When `true`, the charge is due and invoiced immediately. When `false`, it is due and invoiced at the end of each billing period. |
    | `prorated` | boolean | When `true`, the charge is prorated based on the remaining days in the billing period. When `false`, it is billed in full. |
    | `min_amount_cents` | bigint | Minimum amount to charge for each billing period, excluding taxes, in cents. |
    | `properties` | json | JSON object holding the pricing properties of the charge model, with the same structure as the charge `properties` in the API (for example `amount` for a standard charge or `graduated_ranges` for a graduated one). |
    | `charge_filters` | json | JSON array of the charge filters used to apply differentiated pricing. Each item holds `invoice_display_name`, `properties` (pricing properties for the filter) and `values`, an array of objects mapping a billable metric filter identifier to the list of filter values. Empty when the charge has no filter. |

  </Accordion>
  <Accordion title="plans">
    One row per plan that is not deleted, including plans that override a parent plan for a single subscription.

    Plans and subscriptions only: empty for organizations billing with the product catalog.

    | Column | Type | Description |
    | --- | --- | --- |
    | `organization_id` | string | Unique identifier of the organization, assigned by Lago. |
    | `lago_id` | string | Unique identifier of the plan, assigned by Lago. |
    | `name` | string | Name of the plan. |
    | `invoice_display_name` | string | Name displayed on invoices. When empty, the plan name is used. |
    | `created_at` | timestamp | Date and time the plan was created, in UTC. |
    | `updated_at` | timestamp | Date and time the plan was last updated, in UTC. |
    | `code` | string | Code of the plan, a unique identifier used for example when assigning a subscription. |
    | `plan_interval` | string | Interval used for recurring billing: `weekly`, `monthly`, `yearly` or `quarterly`. Empty for `semiannual` plans, which this column does not map. |
    | `description` | string | Description of the plan. |
    | `amount_cents` | bigint | Base cost of the plan, excluding taxes, billed on a recurring basis, in cents. It is 0 for a pay-as-you-go plan. |
    | `amount_currency` | string | Currency of the plan, used for its base cost and usage-based charges. |
    | `trial_period` | float | Duration in days during which the base cost of the plan is offered for free. |
    | `pay_in_advance` | boolean | When `true`, the base cost of the plan is due at the beginning of each billing period. When `false`, it is due at the end of the period. |
    | `bill_charges_monthly` | boolean | When `true`, usage-based charges are invoiced monthly even if the plan interval is yearly or semiannual. |
    | `parent_id` | string | Unique identifier of the parent plan, assigned by Lago. Set on plans that override a parent plan for a single subscription, empty on standard plans. |
    | `lago_taxes_ids` | json | JSON array of the unique identifiers of the taxes applied to the plan, assigned by Lago. |

  </Accordion>
  <Accordion title="subscriptions">
    One row per subscription of a customer to a plan.

    Plans and subscriptions only: empty for organizations billing with the product catalog.

    | Column | Type | Description |
    | --- | --- | --- |
    | `organization_id` | string | Unique identifier of the organization, assigned by Lago. |
    | `lago_id` | string | Unique identifier of the subscription, assigned by Lago. |
    | `external_id` | string | Subscription external unique identifier (provided by your own application). |
    | `lago_customer_id` | string | Unique identifier of the customer, assigned by Lago. |
    | `name` | string | Display name of the subscription on invoices. |
    | `lago_plan_id` | string | Unique identifier of the plan of the subscription, assigned by Lago. |
    | `status` | string | Status of the subscription: `pending`, `active`, `terminated` or `canceled`. Empty for `incomplete` subscriptions (waiting for a gating payment), which this column does not map. |
    | `billing_time` | string | Billing time of the subscription: `calendar` or `anniversary`. It determines when recurring billing cycles start. |
    | `subscription_at` | timestamp | Anniversary date and time of the initial subscription, in UTC. It is the basis for billing subscriptions with `anniversary` billing time. |
    | `started_at` | timestamp | Effective start date and time of the subscription, in UTC. Empty if the subscription is `pending` or `canceled`. |
    | `trial_ended_at` | timestamp | Date and time the free trial ended, in UTC. |
    | `ending_at` | timestamp | Effective end date and time of the subscription, in UTC. When empty, the subscription renews automatically. |
    | `terminated_at` | timestamp | Date and time the subscription was terminated, in UTC. Set when the status is `terminated`. |
    | `canceled_at` | timestamp | Date and time the subscription was canceled, in UTC. Set when the status is `canceled`. |
    | `created_at` | timestamp | Date and time the subscription was created, in UTC. |
    | `updated_at` | timestamp | Date and time the subscription was last updated, in UTC. |
    | `lago_next_subscriptions_id` | json | JSON array of the unique identifiers of the subscriptions that replace this one after an upgrade or downgrade, assigned by Lago. Empty array when there is none. |
    | `lago_previous_subscription_id` | string | Unique identifier of the subscription this one replaces after an upgrade or downgrade, assigned by Lago. Empty for a first subscription. |

  </Accordion>

    | `threshold_display_name` | string | Display name of the usage threshold. |

  </Accordion>

## Integrations

<AccordionGroup>
  <Accordion title="integration_customers">
    One row per link between a customer and an accounting, tax or CRM integration.

    | Column | Type | Description |
    | --- | --- | --- |
    | `organization_id` | string | Unique identifier of the organization, assigned by Lago. |
    | `lago_id` | string | Unique identifier of the integration customer, assigned by Lago. |
    | `lago_customer_id` | string | Unique identifier of the customer, assigned by Lago. |
    | `lago_integration_id` | string | Unique identifier of the integration connection, assigned by Lago. |
    | `external_customer_id` | string | Customer ID within the integration's system. Empty when the customer has not been created in that system yet. |
    | `type` | string | Type of integration: `IntegrationCustomers::NetsuiteCustomer`, `IntegrationCustomers::XeroCustomer`, `IntegrationCustomers::QuickbooksCustomer`, `IntegrationCustomers::AnrokCustomer`, `IntegrationCustomers::AvalaraCustomer`, `IntegrationCustomers::HubspotCustomer` or `IntegrationCustomers::SalesforceCustomer`. |
    | `settings` | json | Integration-specific settings, such as `sync_with_provider`, `subsidiary_id` (NetSuite) or `targeted_object` and `email` (HubSpot). |
    | `created_at` | timestamp | Date and time the row was created, in UTC. |
    | `updated_at` | timestamp | Date and time the row was last updated, in UTC. |

  </Accordion>
</AccordionGroup>

## Deleted records

<AccordionGroup>
  <Accordion title="record_deletions">
    One row per hard-deleted record of a tracked table, kept for one month so the deletion can be applied to your copy of the data.

    | Column | Type | Description |
    | --- | --- | --- |
    | `organization_id` | string | Unique identifier of the organization, assigned by Lago. |
    | `lago_id` | string | Unique identifier of the deletion record, assigned by Lago. |
    | `table_name` | string | Table the deleted record belonged to: `fees`, `fees_taxes`, `invoice_subscriptions`, `invoices_taxes`, `credit_notes_taxes`, `billing_entities_taxes`, `customers_taxes`, `rate_cards_taxes`, `plans_taxes` or `contract_rate_cards_terms`. |
    | `lago_record_id` | string | Unique identifier of the deleted record, matching its `lago_id` in `table_name`. |
    | `deleted_at` | timestamp | Date and time the record was deleted, in UTC. |
    | `created_at` | timestamp | Date and time the row was created, in UTC. |
    | `updated_at` | timestamp | Date and time the row was last updated, in UTC. |

  </Accordion>
</AccordionGroup>
