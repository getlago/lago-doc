title: "Airbyte (ETL)"
---

Airbyte is an open-source **data integration platform** used as an ETL. With this integration, you can connect Lago billing data to any warehouse.

## Destinations
You can push Lago billing data to destinations such as Snowflake, BigQuery, Redshift, S3 buckets or Azure.
The entire list is in Airbyte's [destinations documentation](https://docs.airbyte.com/integrations/destinations/).

## Data available for extraction
With Airbyte's native integration of Lago, you can push the following billing data to warehouses:
- billable_metrics
- plans
- coupons
- add_ons
- invoices
- customers
- subscriptions

<Warning>
At present this connector **only supports full refresh syncs**, meaning that each time you use the connector it syncs all available records from scratch. Use it with care if you expect a lot of records.
</Warning>

Find the full documentation of [Airbyte's native Lago integration](https://docs.airbyte.com/integrations/sources/getlago/).

## 1. Connect Lago to Airbyte
You only need your Lago private API key.
In Airbyte:
- Go to **Sources**;
- Select **GetLago** as a source of data; and
- Paste your Lago private API key.

## 3. Sync billing data
This example connects Lago billing data to a Snowflake data warehouse. You can select another destination.

1. Create a **data sync** between Lago source and your destination;
2. Define a **sync frequency**; and
3. Activate the sync in Airbyte between Lago source and your destination.

This populates your Lago billing data into the warehouse (Snowflake in this example).

## 4. Query Lago billing data
Once the data lands in your destination, you can query it. Here is a query calculating your monthly revenue with Lago:

```sql
SELECT
    DATE_TRUNC('MONTH', issuing_date::datetime) AS month,
    SUM(amount_cents) / 100 AS MRR
FROM lago.public.invoices
GROUP BY 1
ORDER BY 1 DESC
```
