Invoice numbering defines how Lago builds the `number` of each finalized invoice. Configure it on the [billing entity](/v2/guide/billing-entities) so numbers match your accounting conventions.

## Settings

| Field | Values | Effect |
| --- | --- | --- |
| `document_numbering` | `per_customer` | One sequence per customer. |
| | `per_billing_entity` | One continuous sequence across all customers of the billing entity. |
| `document_number_prefix` | string or `null` | Prefix applied to document numbers. |

## Configure numbering

<Tabs>
  <Tab title="Dashboard">
    1. Click **Settings** in the side menu;
    2. Open **Billing entity** > **Invoicing settings**;
    3. Edit the **Document numbering** and **Document prefix** blocks; and
    4. Save your changes.
  </Tab>
  <Tab title="API">
    <CodeGroup>
    ```bash Use one sequence per billing entity
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"
    BILLING_ENTITY_CODE="acme_corp"

    curl --location --request PATCH "$LAGO_URL/api/v2/billing_entities/$BILLING_ENTITY_CODE" \
      --header "Authorization: Bearer $API_KEY" \
      --header 'Content-Type: application/json' \
      --data-raw '{
        "billing_entity": {
          "document_numbering": "per_billing_entity",
          "document_number_prefix": "ACM"
        }
      }'
    ```
    </CodeGroup>
  </Tab>
</Tabs>
