The grace period is the number of days invoices stay in `draft` before Lago finalizes them. Use it when your team reviews invoices, or when late usage events can still arrive after the billing period ends.

<Info>
The grace period is a premium feature. On the customer, `invoice_grace_period` is ignored without a premium license.
</Info>

While an invoice is in draft, you can [refresh, finalize or delete it](/v2/guide/invoicing/draft-invoices).

## Example

With a 3-day grace period on `customer_example`, the invoice generated when a billing period of `contract_example` ends stays in draft for 3 days. Events for that period that arrive during those days can be added by [refreshing the draft](/v2/guide/invoicing/draft-invoices#refresh-a-draft-invoice).

## Set the grace period on the billing entity

The billing entity value applies to every customer of the entity that has no value of its own.

<Tabs>
  <Tab title="Dashboard">
    1. Click **Settings** in the side menu;
    2. Open **Billing entity** > **Invoicing settings**;
    3. Click **Edit** in the **Grace period** block;
    4. Enter the number of days; and
    5. Click **Edit grace period**.
  </Tab>
  <Tab title="API">
    <CodeGroup>
    ```bash Set a 3-day grace period on a billing entity
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"
    BILLING_ENTITY_CODE="acme_corp"

    curl --location --request PATCH "$LAGO_URL/api/v2/billing_entities/$BILLING_ENTITY_CODE" \
      --header "Authorization: Bearer $API_KEY" \
      --header 'Content-Type: application/json' \
      --data-raw '{
        "billing_entity": {
          "invoice_grace_period": 3
        }
      }'
    ```
    </CodeGroup>
  </Tab>
</Tabs>

## Set the grace period on a customer

A customer value overrides the billing entity value for that customer only.

<Tabs>
  <Tab title="Dashboard">
    1. Open **Customers** and select a customer;
    2. Open the **Settings** tab;
    3. Click **Add grace period** in the **Grace period** block; and
    4. Enter the number of days and confirm.
  </Tab>
  <Tab title="API">
    <CodeGroup>
    ```bash Set a 5-day grace period on a customer
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"

    curl --location --request PATCH "$LAGO_URL/api/v2/customers/customer_example" \
      --header "Authorization: Bearer $API_KEY" \
      --header 'Content-Type: application/json' \
      --data-raw '{
        "customer": {
          "invoice_grace_period": 5
        }
      }'
    ```
    </CodeGroup>
  </Tab>
</Tabs>
