Invoicing settings control how your invoices look and when they are finalized. Configure defaults on the [billing entity](/v2/guide/billing-entities), then use customer-specific settings where available. You can also add custom invoice sections and a purchase order number to a Contract.

## Where each setting lives

| Setting | Purpose | Configure on |
| --- | --- | --- |
| Logo and footer | Add your branding and company details. | Billing entity |
| Document language | Choose the language of invoice documents. | Billing entity or customer |
| Custom sections | Add information such as bank details. | Billing entity, customer or Contract |
| [Grace period](/v2/guide/invoicing/invoicing-settings/grace-period) | Allow time to review draft invoices. | Billing entity or customer |
| [Invoice numbering](/v2/guide/invoicing/invoicing-settings/invoice-numbering) | Choose the numbering sequence and prefix. | Billing entity |
| [Issuing date](/v2/guide/invoicing/invoicing-settings/issuing-date) | Choose the date shown on periodic invoices. | Billing entity or customer |
| [Zero-amount invoices](/v2/guide/invoicing/invoicing-settings/empty-invoices) | Decide whether to finalize invoices with a zero amount. | Billing entity or customer |
| [Taxes](/v2/guide/taxes) | Assign tax rates. | See tax assignment options |
| Email notifications | Configure invoice emails. | Billing entity |

For invoice consolidation and purchase order numbers, see [Contracts](/v2/guide/contracts/overview).

## Update the entity information and logo

<Tabs>
  <Tab title="Dashboard">
    1. Click **Settings** in the side menu.
    2. Open **Billing entity**.
    3. Open **General information**.
    4. Click **Edit** in the **Information** block.
    5. Upload a logo.
    6. Update the entity details.
    7. Click **Save edits**.
  </Tab>
  <Tab title="API">
    `logo` accepts a PNG or JPEG image encoded as a base64 data URL. Replace `__YOUR_PNG_OR_JPEG_DATA_URL__` with your image’s complete data URL, including the `data:image/png;base64,` or `data:image/jpeg;base64,` prefix.

    <CodeGroup>
    ```bash Update the billing entity logo and legal name
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"
    BILLING_ENTITY_CODE="acme_corp"

    curl --location --request PATCH "$LAGO_URL/api/v2/billing_entities/$BILLING_ENTITY_CODE" \
      --header "Authorization: Bearer $API_KEY" \
      --header 'Content-Type: application/json' \
      --data-raw '{
        "billing_entity": {
          "legal_name": "Acme Corp",
          "logo": "__YOUR_PNG_OR_JPEG_DATA_URL__"
        }
      }'
    ```
    </CodeGroup>
  </Tab>
</Tabs>

## Add a custom footer

<Tabs>
  <Tab title="Dashboard">
    1. Click **Settings** in the side menu.
    2. Open **Billing entity**.
    3. Open **Invoicing settings**.
    4. Click **Edit** in the **Invoice default footer** block.
    5. Enter your text.
    6. Click **Save information**.
  </Tab>
  <Tab title="API">
    <CodeGroup>
    ```bash Update the invoice footer
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"
    BILLING_ENTITY_CODE="acme_corp"

    curl --location --request PATCH "$LAGO_URL/api/v2/billing_entities/$BILLING_ENTITY_CODE" \
      --header "Authorization: Bearer $API_KEY" \
      --header 'Content-Type: application/json' \
      --data-raw '{
        "billing_entity": {
          "invoice_footer": "Acme Corp, registered in Delaware."
        }
      }'
    ```
    </CodeGroup>
  </Tab>
</Tabs>

## Set the document language

Set the default on the billing entity. A customer's `document_locale` overrides it.

<Tabs>
  <Tab title="Dashboard">
    1. Click **Settings** in the side menu.
    2. Open **Billing entity**.
    3. Open **Invoicing settings**.
    4. Click **Edit** in the **Document language** block.
    5. Select the language.
    6. Confirm your selection.
  </Tab>
  <Tab title="API">
    <CodeGroup>
    ```bash Set the billing entity document language
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"
    BILLING_ENTITY_CODE="acme_corp"

    curl --location --request PATCH "$LAGO_URL/api/v2/billing_entities/$BILLING_ENTITY_CODE" \
      --header "Authorization: Bearer $API_KEY" \
      --header 'Content-Type: application/json' \
      --data-raw '{
        "billing_entity": {
          "document_locale": "fr"
        }
      }'
    ```
    </CodeGroup>
  </Tab>
</Tabs>

## Add custom invoice sections

A custom invoice section adds a titled block to the invoice, for example bank details. Assign sections by code at three levels:

- **Billing entity**: `invoice_custom_section_codes` applies to every customer of the entity. An empty array removes the assignments.
- **Customer**: `invoice_custom_section_codes` assigns sections to one customer. Set `skip_invoice_custom_sections` to `true` to show none.
- **Contract**: `invoice_custom_section` takes `invoice_custom_section_codes` and `skip_invoice_custom_sections` for one Contract.

<Tabs>
  <Tab title="Dashboard">
    1. Click **Settings**.
    2. Open **Invoice custom sections**.
    3. Click **Add**.
    4. Enter a name.
    5. Enter a code.
    6. Enter the section title.
    7. Enter the content.
    8. Click **Preview** to check the rendering.
    9. Apply the section to a billing entity or a customer.
  </Tab>
  <Tab title="API">
    <CodeGroup>
    ```bash Assign a custom section to a customer
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"

    curl --location --request PUT "$LAGO_URL/api/v2/customers/customer_example" \
      --header "Authorization: Bearer $API_KEY" \
      --header 'Content-Type: application/json' \
      --data-raw '{
        "customer": {
          "skip_invoice_custom_sections": false,
          "invoice_custom_section_codes": ["eu_bank_details"]
        }
      }'
    ```

    ```bash Assign a custom section to a contract
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"

    curl --location --request PATCH "$LAGO_URL/api/v2/contracts/contract_example" \
      --header "Authorization: Bearer $API_KEY" \
      --header 'Content-Type: application/json' \
      --data-raw '{
        "contract": {
          "invoice_custom_section": {
            "invoice_custom_section_codes": ["eu_bank_details"]
          }
        }
      }'
    ```
    </CodeGroup>

    The API assigns existing sections by code. Create the sections themselves in the Dashboard. On a Contract, the lifecycle status determines which fields can still change. See [Contract lifecycle](/v2/guide/contracts/lifecycle).
  </Tab>
</Tabs>
