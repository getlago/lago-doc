Add metadata to link a credit note to records in your other systems, such as an ERP document ID. Each entry has a key and a value.

## Limits

- At most 50 keys per credit note.
- Keys up to 100 characters.
- Values up to 255 characters. Values must be strings or `null`.
- The credit note must be finalized.

<span id="add-or-merge-metadata" />

## Add or update metadata

Add new keys or update existing values. Keys you do not include stay unchanged. In the example below, `synced_to_erp` stores the string `"true"`, not a boolean.

<Tabs>
  <Tab title="Dashboard">
    1. Open the credit note detail page.
    2. Click **Add metadata** or **Edit metadata**.
    3. Enter your key-value pairs.
    4. Click **Save**.
  </Tab>
  <Tab title="API">
    <CodeGroup>
    ```bash Merge metadata keys
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"
    CREDIT_NOTE_ID="__YOUR_CREDIT_NOTE_ID__"

    curl --location --request PATCH "$LAGO_URL/api/v2/credit_notes/$CREDIT_NOTE_ID/metadata" \
      --header "Authorization: Bearer $API_KEY" \
      --header 'Content-Type: application/json' \
      --data-raw '{
        "metadata": {
          "erp_reference": "CN-0001",
          "synced_to_erp": "true"
        }
      }'
    ```
    </CodeGroup>
  </Tab>
</Tabs>

## Replace all metadata

Replacing metadata removes keys you do not include. `POST` replaces the whole set. Omitted `metadata` defaults to an empty object.

<CodeGroup>
```bash Replace all metadata
LAGO_URL="https://api.getlago.com"
API_KEY="__YOUR_API_KEY__"
CREDIT_NOTE_ID="__YOUR_CREDIT_NOTE_ID__"

curl --location --request POST "$LAGO_URL/api/v2/credit_notes/$CREDIT_NOTE_ID/metadata" \
  --header "Authorization: Bearer $API_KEY" \
  --header 'Content-Type: application/json' \
  --data-raw '{
    "metadata": {
      "erp_reference": "CN-0001"
    }
  }'
```
</CodeGroup>

## Delete metadata

Delete one key to remove a single reference, or delete all metadata to clear the credit note’s metadata.

<Tabs>
  <Tab title="Dashboard">
    1. Open the credit note detail page.
    2. Click **Edit metadata**.
    3. Click the trash icon next to the key.
    4. Click **Save**.
  </Tab>
  <Tab title="API">
    <CodeGroup>
    ```bash Delete one key
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"
    CREDIT_NOTE_ID="__YOUR_CREDIT_NOTE_ID__"

    curl --location --request DELETE "$LAGO_URL/api/v2/credit_notes/$CREDIT_NOTE_ID/metadata/synced_to_erp" \
      --header "Authorization: Bearer $API_KEY"
    ```

    ```bash Delete all metadata
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"
    CREDIT_NOTE_ID="__YOUR_CREDIT_NOTE_ID__"

    curl --location --request DELETE "$LAGO_URL/api/v2/credit_notes/$CREDIT_NOTE_ID/metadata" \
      --header "Authorization: Bearer $API_KEY"
    ```
    </CodeGroup>
  </Tab>
</Tabs>

## Retrieve metadata

[Retrieve the credit note](/v2/api-reference/credit-notes/retrieve) with `expands[]=metadata` to include its metadata.

<span id="endpoints" />

<Accordion title="Metadata API operations">
| Method and path | Effect |
| --- | --- |
| `POST /credit_notes` with `metadata` | Sets metadata at creation. |
| `POST /credit_notes/{credit_note_id}/metadata` | Replaces all metadata. |
| `PUT` or `PATCH /credit_notes/{credit_note_id}/metadata` | Merges keys into existing metadata. |
| `PUT` or `PATCH /credit_notes/{lago_id}` with `metadata` | Merges keys. |
| `DELETE /credit_notes/{credit_note_id}/metadata` | Clears all metadata. |
| `DELETE /credit_notes/{credit_note_id}/metadata/{key}` | Deletes one key and returns the remaining metadata. |

The metadata endpoints return only the metadata object, or `null`. To read metadata with the credit note, retrieve it with `expands[]=metadata`.

</Accordion>
