Standard pricing applies the same price to every unit. Use it for a fixed Product with a configured quantity or a metered Product with a quantity measured from events.

## How it works

Amount = quantity × unit price. `amount` accepts decimal unit prices, such as `"0.0004"`.

## Availability

- Fixed Products: available, arrears and advance, with or without proration.
- Metered Products: available for every aggregation except Weighted sum with `recurring: true` and proration. Advance billing is unavailable with Latest, Max and Weighted sum.

See the [availability matrix](/v2/guide/rate-cards/pricing-models/overview#model-availability).

## Configure the rate

Set `rate_model` to `standard` and `rate_properties.amount` to the unit price, as a decimal string in the Rate Card's currency. `amount` is required.

<CodeGroup>
```bash Create a standard rate
LAGO_URL="https://api.getlago.com"
API_KEY="__YOUR_API_KEY__"

curl --location --request POST "$LAGO_URL/api/v2/rate_cards/api_calls_usd/rates" \
  --header "Authorization: Bearer $API_KEY" \
  --header 'Content-Type: application/json' \
  --data-raw '{
    "rate": {
      "code": "calls_standard",
      "effective_from": "2027-01-01T00:00:00Z",
      "rate_model": "standard",
      "rate_properties": { "amount": "0.01" },
      "billing_interval_count": 1,
      "billing_interval_unit": "month"
    }
  }'
```
</CodeGroup>

## Example

This illustration uses two separate Standard Rates in USD over one full month, with no proration or spending minimum:

| Fee | Rate | Quantity | Calculation | Amount before tax |
| --- | --- | --- | --- | --- |
| Monthly service | `amount: "100"` | 1 unit | 1 × 100.00 USD | 100.00 USD |
| API calls | `amount: "0.01"` | 2,000 calls | 2,000 × 0.01 USD | 20.00 USD |
| **Total** | | | | **120.00 USD** |

A zero quantity gives a zero amount, unless the Rate has a [spending minimum](/v2/guide/rate-cards/spending-minimums). The example above has no spending minimum.

## Check the result

Compare the quantity and unit price with the calculated fee. Account for any configured spending minimum separately. Use [Contract current usage](/v2/guide/contracts/current-usage) to inspect provisional values. See [Rates](/v2/guide/rate-cards/rates#check-which-rate-was-used) to check which Rate applies.
