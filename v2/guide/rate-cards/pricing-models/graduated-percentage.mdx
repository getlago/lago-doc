Graduated percentage pricing divides a measured monetary amount into tiers. Each tier applies its own percentage to the amount within it and can include a flat fee.

## How it works

The Product's billable metric measures a monetary amount, such as payment volume. The amount fills tier 1 up to its `to_value`, then tier 2, and so on. Each tier's `rate` applies to the monetary amount within that tier. A tier's `flat_amount` is a flat fee applied once for the whole tier, not per transaction. The last tier has `to_value: null`.

## Availability

- Fixed Products: not available.
- Metered Products: available with Count, Count unique, Max, Sum and Weighted sum, except when metrics use `recurring: true` with proration. Not available with Latest. Advance billing is available only for Count, non-prorated Count unique and non-prorated Sum.

See the [availability matrix](/v2/guide/rate-cards/pricing-models/overview#model-availability).

## Configure the rate

Set `rate_model` to `graduated_percentage` and describe the tiers in `rate_properties.graduated_percentage_ranges`. Each tier uses these fields:

| Field | Description |
| --- | --- |
| `to_value` | Upper bound of the tier, as a decimal string. `null` on the last tier. Bounds must increase. |
| `rate` | Percentage applied to the monetary amount within this tier. |
| `flat_amount` | Flat fee for the tier. Optional. |

Do not send `from_value`.

<CodeGroup>
```bash Create a graduated percentage rate
LAGO_URL="https://api.getlago.com"
API_KEY="__YOUR_API_KEY__"

curl --location --request POST "$LAGO_URL/api/v2/rate_cards/payment_volume_usd/rates" \
  --header "Authorization: Bearer $API_KEY" \
  --header 'Content-Type: application/json' \
  --data-raw '{
    "rate": {
      "code": "payments_graduated_percentage",
      "effective_from": "2027-01-01T00:00:00Z",
      "rate_model": "graduated_percentage",
      "rate_properties": {
        "graduated_percentage_ranges": [
          { "to_value": "1000", "rate": "1", "flat_amount": "200" },
          { "to_value": "10000", "rate": "2", "flat_amount": "300" },
          { "to_value": null, "rate": "3", "flat_amount": "400" }
        ]
      },
      "billing_interval_count": 1,
      "billing_interval_unit": "month"
    }
  }'
```
</CodeGroup>

## Example

This example uses a metered Product, `payment_volume`, measuring transaction amounts in USD. The total is 5,050 USD over one full monthly billing period, with no proration or spending minimum.

| Tier | Up to (`to_value`) | Percentage | Flat fee |
| --- | --- | --- | --- |
| Tier 1 | 1,000 | 1% | 200 USD |
| Tier 2 | 10,000 | 2% | 300 USD |
| Tier 3 | No upper limit (`null`) | 3% | 400 USD |

| Tier | Monetary amount in tier | Calculation | Fee before tax |
| --- | --- | --- | --- |
| Tier 1 | 1,000 USD | 1,000 USD × 1% + 200 USD | 210 USD |
| Tier 2 | 4,050 USD | 4,050 USD × 2% + 300 USD | 381 USD |
| **Total** | **5,050 USD** | | **591 USD** |

Tier 3 is not reached, so its flat fee is not included. The calculated fee is 591 USD before tax.
