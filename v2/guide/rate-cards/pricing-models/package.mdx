Package pricing applies a fixed price to a group of units, such as 100 API calls. Use it when you sell usage in packages.

## How it works

A package has a size (`package_size`) and a price (`amount`). The fee is the number of packages consumed × `amount`.

## Availability

- Fixed Products: not available.
- Metered Products: available for Count, Count unique, Latest, Max, Sum and Weighted sum, except when metrics use `recurring: true` with proration. Advance billing is available only for Count, non-prorated Count unique and non-prorated Sum.

See the [availability matrix](/v2/guide/rate-cards/pricing-models/overview#model-availability).

## Configure the rate

Set `rate_model` to `package`. `rate_properties` takes:

| Field | Required | Description |
| --- | --- | --- |
| `amount` | Yes | Price of one package, as a decimal string. |
| `package_size` | Yes | Units in one package, as an integer. |
| `free_units` | No | Free units per billing period, as an integer. |

<CodeGroup>
```bash Create a package rate
LAGO_URL="https://api.getlago.com"
API_KEY="__YOUR_API_KEY__"

curl --location --request POST "$LAGO_URL/api/v2/rate_cards/api_calls_usd/rates" \
  --header "Authorization: Bearer $API_KEY" \
  --header 'Content-Type: application/json' \
  --data-raw '{
    "rate": {
      "code": "calls_package",
      "effective_from": "2027-07-01T00:00:00Z",
      "rate_model": "package",
      "rate_properties": {
        "amount": "1",
        "package_size": 100,
        "free_units": 0
      },
      "billing_interval_count": 1,
      "billing_interval_unit": "month"
    }
  }'
```
</CodeGroup>

## Example

This example prices 2,000 calls over one full monthly billing period in USD. Each package contains 100 calls and costs 1 USD. It uses no free units, proration or spending minimum:

| Quantity | Packages | Calculation | Amount before tax |
| --- | --- | --- | --- |
| 2,000 calls | 20 | 20 × 1.00 USD | 20.00 USD |

The 2,000 calls fill exactly 20 packages, giving a calculated fee of 20 USD before tax. This example uses complete packages and no free units.

## Check the result

For the complete-package example above, divide the quantity by the package size and multiply the package count by its price. Use [Contract current usage](/v2/guide/contracts/current-usage) to inspect provisional values. See [Rates](/v2/guide/rate-cards/rates#check-which-rate-was-used) to check which Rate applies.
