A payment method is a stored reference to a customer's payment instrument, such as a card or a direct debit mandate, held by the payment provider. Lago never stores the raw details: it keeps the provider's `provider_method_id` and asks the provider to charge it.

## The payment method object

| Field | Meaning |
| --- | --- |
| `lago_id` | Lago identifier, used in the endpoints below. |
| `external_customer_id` | The customer that owns the method. |
| `provider_method_id` | Identifier of the instrument in the provider. |
| `payment_provider_code`, `payment_provider_name`, `payment_provider_type` | The provider connection. |
| `is_default` | Whether it is the customer's default method. |
| `deleted_at` | Set once the method is deleted. |

## Capture a payment method with a checkout URL

A checkout URL sends the customer to the provider's checkout page to register a payment method. The customer must already be [connected to a provider](/v2/guide/payments/payment-providers).

<Tabs>
  <Tab title="Dashboard">
    1. Open the customer;
    2. In **Payment methods**, click **Add a payment method**;
    3. Click **Generate link**; and
    4. Copy the URL and share it with your customer.
  </Tab>
  <Tab title="API">
    No request body is required.

    <CodeGroup>
    ```bash Create a checkout URL
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"

    curl --location --request POST "$LAGO_URL/api/v2/customers/customer_example/checkout_url" \
      --header "Authorization: Bearer $API_KEY"
    ```
    </CodeGroup>

    The response returns `checkout_url` with `checkout_url`, `payment_provider` and `payment_provider_code`.
  </Tab>
</Tabs>

## List a customer's payment methods

<CodeGroup>
```bash List payment methods
LAGO_URL="https://api.getlago.com"
API_KEY="__YOUR_API_KEY__"

curl --location --request GET "$LAGO_URL/api/v2/customers/customer_example/payment_methods" \
  --header "Authorization: Bearer $API_KEY"
```
</CodeGroup>

The list is cursor-paginated and accepts `created_at_from` and `created_at_to`.

## Set the default payment method

The default method is used when a payment request or a retry does not select one. No request body is required.

<CodeGroup>
```bash Set the default payment method
LAGO_URL="https://api.getlago.com"
API_KEY="__YOUR_API_KEY__"
PAYMENT_METHOD_ID="__YOUR_PAYMENT_METHOD_ID__"

curl --location --request PUT "$LAGO_URL/api/v2/customers/customer_example/payment_methods/$PAYMENT_METHOD_ID/set_as_default" \
  --header "Authorization: Bearer $API_KEY"
```
</CodeGroup>

## Delete a payment method

<Warning>
Deleting a payment method stops Lago from charging it. Collections that relied on it need another method. Review the change before you run it in production.
</Warning>

<CodeGroup>
```bash Delete a payment method
LAGO_URL="https://api.getlago.com"
API_KEY="__YOUR_API_KEY__"
PAYMENT_METHOD_ID="__YOUR_PAYMENT_METHOD_ID__"

curl --location --request DELETE "$LAGO_URL/api/v2/customers/customer_example/payment_methods/$PAYMENT_METHOD_ID" \
  --header "Authorization: Bearer $API_KEY"
```
</CodeGroup>

The response returns the payment method with `deleted_at` set.

## Choose a payment method per collection

[Payment requests](/v2/guide/payments/payment-requests) and [payment retries](/v2/guide/payments/payment-retries) accept an optional `payment_method` object. Omit it to use the configured default.

| Field | Values |
| --- | --- |
| `payment_method_type` | How the payment is collected: `provider` or `manual`. |
| `payment_method_id` | `lago_id` of a payment method that belongs to the customer. |

```json
{
  "payment_method": {
    "payment_method_type": "provider",
    "payment_method_id": "__YOUR_PAYMENT_METHOD_ID__"
  }
}
```
