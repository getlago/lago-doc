A payment retry asks Lago to collect an unpaid invoice again, for example after a card was declined. A payment URL is a provider checkout link for one invoice that you share with the customer so they can pay it themselves.

## Retry an invoice payment

`POST /invoices/{lago_id}/retry_payment` retries collection using the selected or default payment method. The body is optional:

| Field | Meaning |
| --- | --- |
| `payment_method.payment_method_type` | `provider` or `manual`. |
| `payment_method.payment_method_id` | `lago_id` of a payment method that belongs to the customer. |

Omit `payment_method` to use the configured default. See [Payment methods](/v2/guide/payments/payment-methods).

<Warning>
A retry can charge the customer's payment method. Check the invoice and the payment method before you run it in production.
</Warning>

<Tabs>
  <Tab title="Dashboard">
    1. Open **Invoices** and go to the **Outstanding** tab;
    2. Click the **ellipsis icon** on the invoice; and
    3. Select **Resend for collection**.
  </Tab>
  <Tab title="API">
    <CodeGroup>
    ```bash Retry with the default payment method
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"
    INVOICE_ID="__YOUR_INVOICE_ID__"

    curl --location --request POST "$LAGO_URL/api/v2/invoices/$INVOICE_ID/retry_payment" \
      --header "Authorization: Bearer $API_KEY"
    ```

    ```bash Retry with a specific payment method
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"
    INVOICE_ID="__YOUR_INVOICE_ID__"

    curl --location --request POST "$LAGO_URL/api/v2/invoices/$INVOICE_ID/retry_payment" \
      --header "Authorization: Bearer $API_KEY" \
      --header 'Content-Type: application/json' \
      --data-raw '{
        "payment_method": {
          "payment_method_type": "provider",
          "payment_method_id": "__YOUR_PAYMENT_METHOD_ID__"
        }
      }'
    ```
    </CodeGroup>
  </Tab>
</Tabs>

Follow the result on the invoice `payment_status` (`pending`, `succeeded`, `failed`) or in `GET /payments?invoice_id=...`.

## Create a payment URL

`POST /invoices/{lago_id}/payment_url` returns a URL where the customer can pay the invoice through the payment provider. It requires a customer [connected to a provider](/v2/guide/payments/payment-providers). A provider rate limit returns `429`.

<CodeGroup>
```bash Create a payment URL
LAGO_URL="https://api.getlago.com"
API_KEY="__YOUR_API_KEY__"
INVOICE_ID="__YOUR_INVOICE_ID__"

curl --location --request POST "$LAGO_URL/api/v2/invoices/$INVOICE_ID/payment_url" \
  --header "Authorization: Bearer $API_KEY"
```
</CodeGroup>

The response returns `payment_url` with `payment_url`, `payment_provider`, `lago_invoice_id` and `external_customer_id`.
