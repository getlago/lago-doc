A payment receipt documents a payment recorded in Lago. Use it to share proof of payment with your customer.

<Info>
Payment receipts are a premium add-on, available on request.
</Info>

An invoice records what is billed. A receipt documents a payment against that balance. Use the payment linked to each receipt to reconcile partial payments.

<span id="list-and-retrieve-receipts" />

## Find a receipt

The list returns every receipt of the organization, newest first. Filter with `invoice_id`, `created_at_from` and `created_at_to`. `invoice_id` also returns receipts for payments made through a payment request covering that invoice. An unknown invoice returns an empty list.

<CodeGroup>
```bash List receipts for an invoice
LAGO_URL="https://api.getlago.com"
API_KEY="__YOUR_API_KEY__"
INVOICE_ID="__YOUR_INVOICE_ID__"

curl --location --request GET "$LAGO_URL/api/v2/payment_receipts?invoice_id=$INVOICE_ID" \
  --header "Authorization: Bearer $API_KEY"
```

```bash Retrieve a receipt with its payment
LAGO_URL="https://api.getlago.com"
API_KEY="__YOUR_API_KEY__"
RECEIPT_ID="__YOUR_RECEIPT_ID__"

curl --globoff --location --request GET "$LAGO_URL/api/v2/payment_receipts/$RECEIPT_ID?expands[]=payment" \
  --header "Authorization: Bearer $API_KEY"
```
</CodeGroup>

Receipt read access uses the invoice read permission on the API key.


## Download a receipt

1. Open the payment details page.
2. Download the receipt.

Through the API, retrieve the receipt and use `pdf_url` or `xml_url` to download the document. A URL is `null` while the document is unavailable. `pdf_url_expires_at` and `xml_url_expires_at` indicate when the links expire.

## Resend a receipt email

<Info>
Resending requires a premium license, valid recipients and an email configuration on the billing entity.
</Info>

The body accepts optional `to`, `cc` and `bcc` arrays. When `to` is omitted or empty, Lago uses the customer email. A successful response has an empty body and does not confirm email delivery.

<Warning>
Check the recipients before resending the receipt.
</Warning>

<CodeGroup>
```bash Resend a receipt email
LAGO_URL="https://api.getlago.com"
API_KEY="__YOUR_API_KEY__"
RECEIPT_ID="__YOUR_RECEIPT_ID__"

curl --location --request POST "$LAGO_URL/api/v2/payment_receipts/$RECEIPT_ID/resend_email" \
  --header "Authorization: Bearer $API_KEY" \
  --header 'Content-Type: application/json' \
  --data-raw '{
    "to": ["billing@example.com"]
  }'
```
</CodeGroup>
