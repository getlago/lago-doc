Audit logs help you trace changes to billing objects and investigate API requests. Use activity logs for object changes and API logs for request details.

## Activity logs

Activity logs record actions initiated through the Dashboard, the API or the system. Entries identify the affected object, the action and when it occurred. When available, they also identify the user and the changes made.

See [Activity logs](/v2/guide/logs#activity-logs) for Dashboard instructions, filters and API examples.

## API logs

API logs contain recorded requests and their responses. Use them to investigate a failed request or trace changes made by an integration. They do not represent every request sent to Lago.

See [API logs](/v2/guide/logs#api-logs) for request fields, filters and retrieval examples.

## Access and retention

Access requires the relevant permissions, a premium license and available log storage. API keys need `activity_log` or `api_log` read permission for the corresponding endpoint.

Records available through the API are limited to the configured retention period. See [API keys](/v2/guide/security/api-keys) to configure integration access.

## Security events

For authentication, API key and team-access changes, use [Security logs](/v2/guide/security/security-logs).
