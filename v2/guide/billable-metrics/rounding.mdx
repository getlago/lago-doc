Rounding applies a function to a billable metric's aggregated value before it is priced, so you bill whole units or a fixed number of decimals. Use it when the raw aggregate is fractional, such as compute hours or GB-seconds, and your price is per whole unit.

## Rounding options

No rounding applies by default. Set `rounding_function` to one of:

- `ceil`: rounds up.
- `floor`: rounds down.
- `round`: rounds to the nearest value with standard rounding rules.

Set the precision with `rounding_precision`.

## Precision

| Precision | Effect | 123.4567 becomes |
| --- | --- | --- |
| None | Rounds to a whole number. | `123` |
| Positive, `2` | Keeps that many decimal places. | `123.46` |
| Negative, `-1` | Rounds to the left of the decimal point (here, the nearest ten). | `120` |

## Worked example

A `compute_hours` metric sums 10.2 hours in a billing period. The rate is $2.00 per hour.

| `rounding_function` | Billed quantity | Amount |
| --- | --- | --- |
| None | 10.2 | $20.40 |
| `ceil` | 11 | $22.00 |
| `floor` | 10 | $20.00 |
| `round` | 10 | $20.00 |

## Apply rounding

<Tabs>
  <Tab title="Dashboard">
    On the configuration page of your billable metric, enable rounding, select `ceil`, `floor` or `round`, and set an optional precision.
  </Tab>
  <Tab title="API">
    <CodeGroup>
    ```bash Round the aggregated value to 2 decimal places {14,15}
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"

    curl --location --request POST "$LAGO_URL/api/v2/billable_metrics" \
      --header "Authorization: Bearer $API_KEY" \
      --header 'Content-Type: application/json' \
      --data-raw '{
        "billable_metric": {
          "name": "Storage",
          "code": "storage",
          "description": "Number of GB used",
          "aggregation_type": "sum_agg",
          "field_name": "gb",
          "rounding_function": "round",
          "rounding_precision": 2,
          "recurring": false
        }
      }'
    ```
    </CodeGroup>
  </Tab>
</Tabs>

Once the metric is attached to a plan, only its name, description and permitted filter changes can be updated. Set rounding before you attach the metric.
