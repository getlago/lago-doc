The `recurring` flag on a billable metric decides whether its aggregated value resets each billing period or carries over. Set `recurring: false` for consumption you bill per period, such as API calls, and `recurring: true` for state that persists, such as seats.

Metric recurrence and product type answer different questions. `recurring` controls carry-over of the measured value. A [metered product](/v2/guide/product-catalog/metered-products) is a product priced from measured usage, recurring or not.

<Info>
  Only `sum_agg`, `unique_count_agg` and `weighted_sum_agg` metrics can be recurring. A `count_agg`, `max_agg` or `latest_agg` metric is always metered.
</Info>

## Recurring billable metrics

With `recurring: true`, the aggregation persists across billing periods. The accumulated result carries over and is billed in the following periods.

Example: a customer adds 5 seats in January and 2 more in February. With a recurring Count unique metric on `seat_id`, January bills 5 seats and February bills 7.

<Tabs>
  <Tab title="Dashboard">
    Choose the **recurring** option when you create the billable metric.
  </Tab>
  <Tab title="API">
    <CodeGroup>
    ```bash Seats {13}
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"

    curl --location --request POST "$LAGO_URL/api/v2/billable_metrics" \
      --header "Authorization: Bearer $API_KEY" \
      --header 'Content-Type: application/json' \
      --data-raw '{
        "billable_metric": {
          "name": "Seats",
          "code": "seats",
          "aggregation_type": "unique_count_agg",
          "field_name": "seat_id",
          "recurring": true
        }
      }'
    ```
    </CodeGroup>
  </Tab>
</Tabs>

## Metered billable metrics

With `recurring: false`, the aggregation resets to zero at the end of each billing period. The customer is billed only for that period's usage.

Example: the `api_calls` metric counts 2,000 calls in January and 1,500 in February. January bills 2,000 calls ($20.00 at $0.01) and February bills 1,500 ($15.00).

<Tabs>
  <Tab title="Dashboard">
    Choose the **metered** option when you create the billable metric.
  </Tab>
  <Tab title="API">
    <CodeGroup>
    ```bash API calls {12}
    LAGO_URL="https://api.getlago.com"
    API_KEY="__YOUR_API_KEY__"

    curl --location --request POST "$LAGO_URL/api/v2/billable_metrics" \
      --header "Authorization: Bearer $API_KEY" \
      --header 'Content-Type: application/json' \
      --data-raw '{
        "billable_metric": {
          "name": "API calls",
          "code": "api_calls",
          "aggregation_type": "count_agg",
          "recurring": false
        }
      }'
    ```
    </CodeGroup>
  </Tab>
</Tabs>
