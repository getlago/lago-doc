Use these docs to integrate the Lago API, ingest usage, configure pricing, generate invoices, orchestrate payments, or run Lago in your own infrastructure.

## Choose the right starting point

### Evaluate Lago

Read [why billing is difficult](/guide/introduction/why-billing-is-a-nightmare), review [Lago's capabilities](/faq/product-features), and explore the [pricing templates](/templates/introduction). Lago supports recurring subscriptions, usage-based and hybrid plans, prepaid credits, entitlements, coupons, taxes, payments, and revenue analytics.

### Integrate Lago Cloud

Create a Lago Cloud account, copy an API key from your organization settings, and use `https://api.getlago.com/api/v1` as the API base URL. Start with [API authentication](/api-reference/intro), create customers and plans, then [send usage events](/guide/events/ingesting-usage). Treat API keys as secrets and keep them in server-side environment variables or a secret manager.

### Run Lago yourself

Use the [self-hosted overview](/guide/lago-self-hosted/overview) to compare deployment options. The [Docker guide](/guide/lago-self-hosted/docker) covers a local or single-host installation, while the [Helm charts](https://github.com/getlago/lago-helm-charts) support Kubernetes deployments. Before upgrading, read the [compatibility matrix](/guide/lago-self-hosted/compatibility-matrix) and [update guide](/guide/lago-self-hosted/update-instance).

## Common integration paths

### Meter product usage

Define a billable metric, send idempotent events, and aggregate usage into billable units. The [usage ingestion guide](/guide/events/ingesting-usage) explains event payloads and ingestion choices. The [aggregation reference](/guide/billable-metrics/aggregation-types/overview) covers count, sum, unique count, latest value, maximum, weighted sum, and custom expressions.

### Configure pricing and subscriptions

Create plans from reusable charges and fixed fees, then attach subscriptions to customers. Begin with the [plan model](/guide/plans/plan-model), review [usage-based charges](/guide/plans/charges/usage-based-charges), and use the API reference for exact request and response schemas. Lago supports graduated, package, percentage, volume, and custom pricing models.

### Generate invoices and collect payment

Lago calculates fees, produces invoices, and can coordinate payment providers. Read the [invoicing guide](/guide/invoicing/overview), configure [payment integrations](/integrations/introduction), and subscribe to [webhooks](/guide/webhooks) so your application reacts to billing state changes. Webhook consumers should verify signatures, return quickly, and process retries idempotently.

### Build agent-powered billing workflows

Use the [Lago MCP server](/guide/ai-agents/mcp-server) when an AI client needs to search or retrieve documentation through a standard protocol. Use the [agent SDK](/guide/ai-agents/agent-sdk/overview) when your application needs structured billing tools for supported model providers. Keep write actions behind explicit approval and validate all generated inputs before calling the billing API.
